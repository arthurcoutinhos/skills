# Skills Coutinho

Skills de direção criativa e de decisão usadas no Claude.

| Skill | Para que serve |
|---|---|
| crivocoutinho | Crivo Coutinho. Roda antes de qualquer peça visual: levanta a marca, busca referências no Pinterest e no Behance, faz as perguntas que mudam o design, trava a direção e escolhe a ferramenta de imagem. |
| fora-do-obvio | Gera nomes, conceitos, identidades e campanhas fora do clichê do segmento, ancorados na raiz real do cliente. |
| ringuecoutinho | Ringue Coutinho. Testa uma ideia sua: subagentes criam rivais sem ver a sua ideia, a comparação mostra onde ela erra e o veredito entrega a versão corrigida. Serve para qualquer decisão. |
| marchacoutinho | Marcha Coutinho. Calibra o esforço da resposta pela complexidade do pedido e sugere trocar de modelo ou ligar o raciocínio estendido quando necessário. |
| escalacaocoutinho | Escalação Coutinho. Avalia se vale usar subagentes no pedido e, quando vale, sugere quais, para quê e quanto vão gastar do limite, antes de rodar. |

## Como instalar

Jeito mais fácil: cole o link deste repositório no Claude e peça para ele instalar as skills.

Jeito manual:

1. Baixe o repositório (Code, Download ZIP).
2. Compacte a pasta de cada skill em .zip, com o SKILL.md dentro dela.
3. No Claude, abra Configurações, Capacidades, Skills e envie o .zip.

As skills se complementam: o Fora do óbvio gera ideias, o Ringue expõe os erros da ideia escolhida e o Crivo executa a peça visual. A Marcha e a Escalação ajustam o esforço e o uso de subagentes em qualquer pedido.
