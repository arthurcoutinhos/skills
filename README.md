# Skills Coutinho

Skills de direção criativa usadas no Claude.

| Skill | Para que serve |
|---|---|
| crivocoutinho | Crivo Coutinho. Roda antes de qualquer peça visual: levanta a marca, busca referências, faz as perguntas que mudam o design, trava a direção e escolhe a ferramenta de imagem. |
| fora-do-obvio | Gera nomes, conceitos, identidades e campanhas fora do clichê do segmento, ancorados na raiz real do cliente. |

## Como instalar

1. Baixe a pasta da skill (Code, Download ZIP, ou só a pasta desejada).
2. Compacte a pasta da skill em .zip, com o SKILL.md dentro dela.
3. No Claude, abra Configurações, Capacidades, Skills e envie o .zip.

As duas se complementam: o Crivo Coutinho chama o Fora do óbvio na etapa de referências quando os dois estão instalados.
